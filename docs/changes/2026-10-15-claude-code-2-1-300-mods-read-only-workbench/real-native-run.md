● mulix-workbench: CLI 版本未验证或不可用；工作台仅支持 2.1.301

## 结论

- 真实原生命令注册/执行/面板绘制/刷新/关闭在 2.1.302 宿主上可工作。

- 需要用户裁定：更新目标到 2.1.302，或将 CLI 固定回 2.1.301。
